# Little by little

A simple local to-do list with thoughtful motion. Add a task, check it off, or delete it. Your list is saved in this browser’s localStorage. If storage is unavailable, the app still works for the current visit.

Open index.html directly in your browser. No installation or build step is needed. Or serve this folder with any static server, such as:
    
    python3 -m http.server 4180 --bind 127.0.0.1

Then open http://127.0.0.1:4180. No accounts, dependencies, or network services. Reduced-motion preferences are respected.
